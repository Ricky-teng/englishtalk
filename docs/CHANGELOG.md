# 版本紀錄

## v2.8 — 2026-10-09

**複習完可以繼續練習**
- 沒有到期的字時，「開始複習」變成「開始練習」，「再來一輪」也會直接接練習，不再只跳「目前沒有到期的單字」
- 練習挑「此刻記得機率最低」的 20 個字（依 FSRS 遺忘曲線推算），最快會忘的先練；所有題型都能用
- 還沒到期的字一律算練習：作答會記錄（標記 `p`），但不改變複習排程；保持率統計也排除練習作答
- 這條規則同時修好分析頁「專攻最難的字」「用拼字和填空逼自己想出來」等捷徑：以前會讓沒到期的字被提前排程
- 練習時上方顯示「練習模式」說明、翻卡按鈕顯示「練習・不影響排程」；結束畫面可以繼續練或回首頁

## v2.7 — 2026-10-09

**模型選擇**
- 設定裡的模型從文字框改成下拉選單（整理過的 Groq 與 Gemini 模型），依用途分組：適合即時對話／比較慢不建議對話
- 選了就顯示說明卡：速度、聰明程度、適合做什麼、優點、缺點、免費額度（Groq 官方有公布的才列）
- 「對話用」與「查字、新增單字、文法檢查用」分開選；後者有「自動（推薦）」與「跟對話用同一個」
- 「抓取我帳號可用的模型」把清單外的模型加到選單最下面；也可以「自己輸入模型 ID」
- 只顯示目前選的供應商那一組，畫面不會太長

**Gemini 模型更新**
- Google 已限制 2.5 系列只給最近用過的帳號：新使用者預設改成 gemini-3.5-flash-lite（已在用 2.5 的人不受影響）
- 3.x 模型自動把思考設到最低（minimal 或 low），對話不會變慢、JSON 不會被截斷；模型不吃這個設定時自動拿掉重送
- 查字用的模型沒有權限（403）或不存在（404）時，自動退回對話模型

**Groq 推理型模型**
- gpt-oss 自動設 `reasoning_effort: low`、不回傳思考內容；qwen 把思考內容藏起來，避免 `<think>` 被念出來；不支援時自動拿掉

## v2.6 — 2026-10-09

**Groq 穩定性**
- 送出前先在本機排隊：依模型估算這一分鐘已用的請求數與 token（保守取免費額度的 85%），不夠就等；對話最多等 1.5 秒、查字最多 25 秒、文法與補詞性等背景工作讓路
- 查字、新增單字、文法檢查、詞性補查改用另一個模型（預設 llama-3.3-70b-versatile）：額度跟對話用的 8B 分開算，中文與 JSON 也穩得多；不能用（404）時自動退回對話模型；設定裡可改成「跟對話同一個」
- 要 JSON 陣列的請求包成 `{"items":[...]}`，讓 Groq 也能開 JSON 模式；JSON 驗證失敗時自動關掉 JSON 模式重要一次
- 單次 max_tokens 上限 2400、批次查詢每 6 個字一批，避免單一請求就超過每分鐘額度
- 429 依 retry-after（讀得到時）等待；Failed to fetch 在 Groq 多半是被限流，改成等 2.5 秒、10 秒再重試
- 收到回應後用實際 token 用量更正本機帳本

## v2.5 — 2026-10-09

**同一個字的不同意思合成一張卡**
- 查詢結果依英文字分組：bank 是一張卡，底下「銀行」「河岸」各一行，可勾選要加入哪幾個（預設全選）
- 單字本已有這個字時，已收錄的意思打勾顯示，按「補上勾選的意思」併進同一張卡
- 手動新增一個已存在的字但中文不同 → 自動併成另一個意思，不會變兩張卡
- 卡片存 `senses`（每個意思的詞性、中文、例句），`zh` 是合起來的「銀行；河岸」，複習與測驗照常運作
- 單字本列表、翻卡背面、查字彈窗：多個意思時一行一個、標上詞性

**連線更穩（修「Failed to fetch」「查詢失敗」）**
- 所有 API 請求加上逾時與自動重試：網路層失敗、逾時、500/502/503/504 最多重試 2 次；429 等 4 秒重試一次；401/403/404 不重試
- 對話串流只在還沒收到回應前重試，不會重複念
- Gemini 2.5 Flash 系列關掉「思考」：思考用的 token 會吃掉輸出額度，造成 JSON 被截斷 →「查詢失敗」，也讓第一句變慢；其他模型則多給 2048 token 額度
- 回覆因為 token 上限被截斷時，自動用兩倍額度再要一次
- 回傳陣列的請求（新增單字搜尋、批次查詢、詞性變化、文法、挖字、口說題目）在 Gemini 開啟 JSON 模式
- 錯誤訊息改成人話（沒有網路、連不上、伺服器忙、金鑰格式不對），查字彈窗與新增單字失敗時有「重試」按鈕

## v2.4 — 2026-10-08

**新增單字改成「先查再挑」**
- 「＋ 新增單字」改成一個查詢框：輸入中文 → 列出可以表達它的英文字（最多 6 個，附用法差別）；輸入英文 → 列出它的各個意思（一個意思一張卡）
- 每張候選卡有音標、詞性、中文、用法說明、例句、詞形與詞性變化，按「＋ 加入」直接進單字本，或「改一下再加入」打開完整表單
- 已有這個字但意思不同 → 按鈕變成「補上這個意思」，把新意思接在後面（銀行；河岸）
- 可先選好「加到標籤」，一次加好幾個都會套用
- 同一個查詢永久快取，不再花 API；查詢結果也順便存成單字查詢快取

**手動填寫的表單**
- 英文、中文擺在最上面，填一個就能按「✨ 用 AI 補齊」：只填中文會列出候選讓你挑，填了多義字也會讓你挑意思
- 只填中文時按 Enter 會先幫你查，不會跳出「英文不能空白」
- 例句、近義、反義、詞性變化收進「更多欄位」，畫面不再一打開就一長串
- 範例文字改成「例：…」斜體淡色，不會再被誤以為是已經填好的內容

## v2.3 — 2026-10-08

**詞形與詞性變化**
- 查字彈窗在意思底下顯示「詞形」（過去式、過去分詞、現在分詞、第三人稱、複數、比較級、最高級；過去式和過去分詞相同時合併）與「詞性」（同字根不同詞性的字，附 n./v./adj./adv. 與中文），詞性的字可以點下去接著查
- 新查的字在同一次查詢裡就帶回來，不多花 API；以前查過或已在單字本的字，第一次打開時補查一次後永久快取
- 單字本「補齊詞性變化」按鈕：舊單字每 25 個合成一個請求補完
- 單字本列表、翻卡背面都會顯示；編輯單字可以自己輸入課本上的詞性變化（`decision n. 決定, decisive adj. 果斷的`）

## v2.2 — 2026-10-08

**文法修正，標在句子旁邊**
- 每句說完就在那句底下顯示修正：逐字差異（刪除紅線、新增綠底）、錯誤類型、一行中文規則說明
- 🔊 聽正確說法、🎤 直接跟讀修正後的句子
- AI 不在對話中糾正你，修正不念出來；語音辨識錯誤、標點、贅字、自然的口語省略都不算錯
- 省額度：同時只跑一個請求、排隊的句子合併送出（實測 3 句 → 2 次）、短句不送、Gemini 用額度另計的 flash-lite（404 自動退回對話模型）、429 冷卻後重送
- 設定可選「即時／對話結束後／關閉」；總結卡顯示幾句有更好的說法；修正存進紀錄，逐字稿看得到
- 個人分析新增「常犯的文法錯誤」圖表與建議

**FSRS 排程**
- 預設改用 FSRS-5（Anki 現行演算法），翻卡按鈕顯示各評分會排到幾天後
- 測驗題答對只算「普通」、只有翻卡的「簡單」算「簡單」，避免拼對一次就被排到兩週後
- 目標記憶率 85% / 90% / 95% 可調；可切回 SM-2，兩套狀態同步保存，切換時依上次複習日重排
- 舊卡自動轉換（SM-2 間隔 → 穩定度、難易度係數 → 難度），不需要重來
- 個人分析顯示「依遺忘曲線推算，你現在大約還記得幾個字」

## v2.1 — 2026-10-07

**多種複習方式**（全部不用出聲，翻卡仍是預設）
- ✅ 看英選中、🔁 看中選英：干擾選項同詞性優先、太像的中文會排除；答對自動跳下一題，1–4 鍵作答
- 🧩 例句填空：要填出句子裡的正確詞形（negotiated）；只打原形算對但會提醒
- ⌨️ 拼字、🎧 聽寫：差一個字母算「差一點」；答錯可以照打一次加深印象；提示一次多給一個字母
- 🔀 混合（推薦）：依熟練度自動換題型，新字先認、熟了再逼你寫；錯的字這輪最後用較簡單的題型再考一次
- 🎮 配對遊戲：限時配對、記錄最佳成績，只是暖身，不影響複習排程
- 作答前整張題目卡不能點字查詢，避免偷看答案
- 所有作答（含翻卡、用說的）都會記錄題型與作答時間，給個人分析用

**個人分析**（紀錄頁，全部在本機計算）
- 規則產生的個人化建議，每條都附「直接開練」按鈕：認得卻沒說出口的字、認得型 vs 產出型題目的落差、反覆忘記的字、萬用字（very、good…）與替代說法、句長變化、這週新說出的字、記憶保持率、最常練習的時段
- 圖表：單字掌握度、各題型答對率、各課進度、未來 7 天複習量、每週平均句長；每張都有 hover 說明與數字表格
- 🤖 AI 教練週報：手動產生、同一週只呼叫一次 API，會挑你說過的句子給「更自然的說法」

## v2.0 — 2026-09-30

**全站點字查詢**（這版的必做項目）
- 網站上任何地方的英文字都能點來查：你自己說的話、單字本、例句、複習卡背面、對話紀錄、跟讀視窗、查詢彈窗內的例句
- 滑鼠移過去淡淡標示；反白 2–4 個字的片語會出現「查詢」按鈕
- 在對話框裡點字，查詢彈窗會跟著移進對話框，不會被蓋住
- 還沒翻面的複習卡、輸入框、按鈕、設定頁、音標、全大寫縮寫不觸發
- 查詢彈窗多了這個字的複習／說出次數，以及「🎤 跟讀」例句

**🎤 用說的複習**（新）
- 看中文、聽 AI 的問題、用英文單字說一句話回答；本地判斷、自動評分
- 提示階梯：首字母 → 發音 → 公布答案；「我有說對」可更正辨識錯誤；也可以打字
- 題目批次產生並快取在卡片上，同一個字之後複習 0 次 API；失敗時改用通用題目
- 每輪最多 10 張，結束有統計；答對也算一次「說出來」

**🗣️ 跟讀練發音**（新）
- AI 每句話、每個例句都能跟讀，逐字標出沒被聽懂的字並給百分比，可慢速播放
- 刻意不做詞幹化，抓得到字尾 -ed、-s 被吃掉的問題
- 對話中開跟讀會自動暫停、再恢復對話麥克風

**其他**
- 可安裝成 App（PWA），離線可開；桌面捷徑直達對話／複習／單字本
- 對話結束總結卡、對話頁歡迎面板（連續天數、今日進度、快速開始）
- 設定頁「測試連線」
- AI 訊息的「再聽」「跟讀」放在標題列，不再佔高度
- 複習進行中收起上方控制列，手機上卡片完整可見
- 新功能介紹：老使用者第一次打開新版本時顯示一次；設定頁底部可再打開
