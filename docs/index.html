新增單字

英文或中文填一個就好，按「用 AI 補齊」會列出候選讓你挑，而且只補空白的欄位，不會改你自己填的內容。

更多欄位：例句、近義詞、反義詞、詞性變化
用逗號分隔，中文放在括號裡（可省略）。

批次貼上單字

直接貼課本的單字表。每行一個，支援 單字、單字 中文、 單字,中文、單字<tab>中文。

不勾選的話就完全照你貼的內容存，一個字都不改，也不會用到 API 額度 —— 課本上的中文跟老師給的定義要一模一樣時選這個。
勾選時：你自己填的中文會被保留，AI 只補空白的欄位；一次最多 20 個字。
