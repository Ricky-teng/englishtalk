# English Talk — 雙工英文對話練習

用嘴巴跟 AI 即時聊英文。AI 說話時你隨時可以插話打斷，就像跟真人講話。
內建單字本與間隔重複複習，而且**你正在背的單字，AI 會在聊天中自然用出來**。

純靜態網站，沒有後端、沒有資料庫、沒有帳號。丟到任何免費靜態主機就能上線。

---

## 架構：為什麼不用錢

| 環節 | 用什麼 | 誰付錢 |
|---|---|---|
| 語音辨識（你說的話 → 文字） | 瀏覽器內建 Web Speech API | 沒人付，免費無限 |
| 語音合成（AI 回覆 → 聲音） | 瀏覽器內建 speechSynthesis | 沒人付，免費無限 |
| 對話模型 | Gemini 或 Groq，**使用者自備金鑰** | 每個使用者用自己的免費額度 |

關鍵在最後一列：金鑰存在**每個使用者自己的瀏覽器**裡，請求也是從他們的瀏覽器直接發給
Google／Groq，完全不經過你的伺服器。所以不管多少人用這個網站，你的花費都是零，
也不可能有人刷爆你的額度。

所有資料（單字本、對話紀錄、統計）都存在使用者自己的 `localStorage`。
你不持有任何人的資料，自然也沒有隱私與法遵問題。

## 部署

整個專案就是這個資料夾裡的靜態檔案，沒有建置步驟（no build step）。

> **必須是 HTTPS。** 瀏覽器只在安全來源才給麥克風權限。
> 下面每個平台都自動附免費 HTTPS，`localhost` 也算安全來源。

### GitHub Pages（最省事）

```bash
git init && git add . && git commit -m "English Talk"
git branch -M main
git remote add origin https://github.com/<你的帳號>/<repo>.git
git push -u origin main
```

到 repo 的 Settings → Pages → Source 選 `main` 分支、資料夾選 `/ (root)`，
一分鐘後就會有 `https://<你的帳號>.github.io/<repo>/`。

### Vercel

```bash
npx vercel        # 第一次會問幾個問題，Framework 選 "Other"
npx vercel --prod
```

或直接在 vercel.com 匯入 GitHub repo。若這些檔案放在 repo 的子資料夾，
在專案設定的 **Root Directory** 填那個子資料夾名稱即可。

### Netlify / Cloudflare Pages

拖曳整個資料夾到 [app.netlify.com/drop](https://app.netlify.com/drop) 就上線了。
走 Git 連動的話，build command 留空，publish directory 填這個資料夾。

## 使用者第一次要做的事

1. 申請一組免費金鑰（二選一，兩個都填也行，隨時可切換）
   - **Gemini**（推薦）：<https://aistudio.google.com/apikey>
   - **Groq**（回應最快）：<https://console.groq.com/keys>
2. 開網站 → 右上角「設定」→ 貼上金鑰 → 儲存
3. 按「開始對話」→ 允許麥克風 → 開始講英文

建議用 **Chrome 或 Edge**。語音辨識只有這兩個支援，
而 Edge 還能拿到 Microsoft 的神經語音（設定裡名字有 Natural / Online 的那些），音質最好。

## 功能

**雙工對話**
麥克風全程不關。AI 說話時同時跑兩道判斷 —— 音量 VAD（開啟回音消除，持續 220ms
超過噪音底即觸發）與辨識文字的回音比對（跟 AI 正在唸的句子重疊超過 60% 就當成喇叭回音丟掉）。
偵測到你出聲就立刻停止播放、中止模型串流、切回聆聽。
LLM 是邊串流邊切句子送去合成，第一句大約 1 秒內出聲。

**單字本**
點對話裡任何一個英文字，AI 會查出音標、詞性、繁中意思與例句，一鍵收進單字本。
也可以「批次加入」直接貼上整課單字表（逗號、換行、`單字 中文` 混排都認得），
加上標籤（例如「第三課」）就能照課程分組複習。可匯出 CSV 給 Anki 或 Excel。

**間隔重複複習**
SM-2 演算法：記得越牢，下次出現得越晚；答錯的當天再出現一次。
四個評分鍵（忘記／困難／普通／簡單），鍵盤空白鍵翻牌、`1`–`4` 評分。

**單字會回到對話裡**
設定裡的「讓 AI 在對話中自然用到我正在複習的單字」預設開啟。
到期與新加入的單字會被塞進系統提示，AI 會找機會把它們講出來。
「背過 → 在對話裡遇到 → 自己講出來」這個循環，比單純刷卡有效得多。

**練習紀錄**
連續天數、每週與累計練習時間、開口字數、練習熱力圖，以及每一場對話的完整逐字稿。
可整包匯出備份（**不含金鑰**）換裝置用。

## 兩個已知限制

**Groq 的跨來源政策**
Gemini 官方就支援瀏覽器直連，最穩定，所以預設用它。Groq 多數情況也可以，
但萬一被瀏覽器擋下，程式會顯示明確訊息請使用者改用 Gemini —— 不會靜默失敗。

**微軟 Edge 朗讀服務（設定裡的第二個語音選項）**
音質最好且免費無限，但微軟會擋部分來源 IP（雲端與資料中心幾乎都被擋，
一般家用網路通常沒問題）。連不上時會自動退回瀏覽器內建語音並在對話中告知，
不會中斷練習。

## 疑難排解

**按了開始卻沒反應／沒有麥克風權限**
確認網址是 `https://` 或 `localhost`。點網址列左側的圖示把麥克風改成「允許」。

**AI 一直自問自答**
麥克風收到喇叭的聲音了。戴耳機，或把設定裡的「搶話靈敏度」調成「低靈敏」。

**出現 429 或額度錯誤**
免費額度暫時用完。等幾分鐘，或到設定切換另一個供應商。

**模型 404 / model not found**
供應商汰換模型了。到設定按「抓取可用清單」重選一個即可。

**換電腦後資料不見**
資料存在瀏覽器本機。到「紀錄 → 匯出備份」存成 JSON，在新裝置匯入。
