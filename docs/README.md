# English Talk — 雙工英文對話練習

用嘴巴跟 AI 即時聊英文。AI 說話時你隨時可以插話打斷，就像跟真人講話。
內建單字本與間隔重複複習，而且**你正在背的單字，AI 會在聊天中自然用出來**。

純靜態網站，沒有後端、沒有資料庫、沒有帳號。丟到任何免費靜態主機就能上線。

---

## 架構：為什麼不用錢

| 環節 | 用什麼 | 誰付錢 |
|---|---|---|
| 語音辨識（你說的話 → 文字） | 瀏覽器內建 Web Speech API | 沒人付，免費無限 |
| 語音合成（AI 回覆 → 聲音） | 瀏覽器內建 speechSynthesis | 沒人付，免費無限 |
| 對話模型 | Gemini 或 Groq，**使用者自備金鑰** | 每個使用者用自己的免費額度 |

關鍵在最後一列：金鑰存在**每個使用者自己的瀏覽器**裡，請求也是從他們的瀏覽器直接發給
Google／Groq，完全不經過你的伺服器。所以不管多少人用這個網站，你的花費都是零，
也不可能有人刷爆你的額度。

所有資料（單字本、對話紀錄、統計）都存在使用者自己的 `localStorage`。
你不持有任何人的資料，自然也沒有隱私與法遵問題。

## 部署

整個專案就是這個資料夾裡的靜態檔案，沒有建置步驟（no build step）。

> **必須是 HTTPS。** 瀏覽器只在安全來源才給麥克風權限。
> 下面每個平台都自動附免費 HTTPS，`localhost` 也算安全來源。

### GitHub Pages（最省事）

GitHub Pages 只能從 repo 的 `/`（根目錄）或 `/docs` 發佈。
所以如果這些檔案放在子資料夾，**資料夾要叫 `docs`**：

```bash
git add . && git commit -m "English Talk"
git push -u origin main
```

到 repo 的 Settings → Pages → Source 選 **Deploy from a branch**、
Branch 選 `main`、資料夾選 `/docs`，一分鐘後就會有
`https://<你的帳號>.github.io/<repo>/`。

免費帳號只能發佈 public repo。頁面裡所有路徑都是相對路徑，放在子路徑底下也能正常載入。

### Vercel

```bash
npx vercel        # 第一次會問幾個問題，Framework 選 "Other"
npx vercel --prod
```

或直接在 vercel.com 匯入 GitHub repo。若這些檔案放在 repo 的子資料夾，
在專案設定的 **Root Directory** 填那個子資料夾名稱（例如 `docs`）即可。

### Netlify / Cloudflare Pages

拖曳整個資料夾到 [app.netlify.com/drop](https://app.netlify.com/drop) 就上線了。
走 Git 連動的話，build command 留空，publish directory 填這個資料夾。

## 功能

**雙工對話**
麥克風全程不關。AI 說話時同時跑兩道判斷 —— 音量 VAD（開啟回音消除，持續 220ms
超過噪音底即觸發）與辨識文字的回音比對（跟 AI 正在唸的句子重疊超過 60% 就當成喇叭回音丟掉）。
偵測到你出聲就立刻停止播放、中止模型串流、切回聆聽。
LLM 是邊串流邊切句子送去合成，第一句大約 1 秒內出聲。

**單字本 — 三種加入方式**
1. **對話中點單字**：點 AI 訊息裡任何一個英文字，AI 查出音標、詞性、繁中意思、例句，
   以及**近義詞與反義詞**（各最多 3 個，同詞性同語意，沒有反義詞就不硬掰）。
   近義／反義詞本身也可以點 —— 彈窗會原地換成那個字，可以一路探索下去，
   已經在單字本裡的會標成已收錄。
2. **手動新增**：每個欄位都自己填，照課本寫。只填英文的話可以按「用 AI 補齊」，
   而且它只補空白欄位，絕不覆蓋你自己打的內容。
3. **批次貼上**：直接貼整課單字表。支援 `單字`、`單字 中文`、`單字,中文`、`單字<tab>中文`，
   會自動剝掉 `adj.`、`(v.)` 這類詞性標記。**可以不勾「用 AI 補齊」**，
   完全照你貼的內容存、一個字都不改，也不花 API 額度 ——
   課本或老師給的定義要一模一樣時用這個。

加上標籤（例如「第三課」）就能照課程分組複習，可匯出 CSV 給 Anki 或 Excel。

**間隔重複複習**
SM-2 演算法：記得越牢，下次出現得越晚；答錯的當天再出現一次。
四個評分鍵（忘記／困難／普通／簡單），鍵盤空白鍵翻牌、`1`–`4` 評分。

**單字會回到對話裡（這是整個專案的核心）**
每一輪對話都會把一池候選字（到期的、新的、還沒說出口過的優先）交給模型，
由它自己挑跟當下話題搭得起來的一兩個，把話題輕輕帶過去用出來，
並問一個「會讓你自己也用到那個字」的問題。畫面上完全不提示是哪些字 ——
看得到答案就變成看字念句，不是真的想得起來。

然後程式會偵測**你有沒有自己把那個字說出來**（支援詞形變化與片語：
`negotiated`、`negotiating` 都算 `negotiate`，`carried out` 算 `carry out`）。
說出來就記一次「產出」。

產出跟卡片複習是**完全分開的兩條線**：
- `複習 N 次` = 認得（看卡片答得出來）
- `說出 N 次` = 說得出來（對話中自己用出來）

產出不會動到 SM-2 的複習排程 —— 它是獨立的第二項指標，
因為「在對話中脫口而出」跟「看卡片想得起來」是兩種不同的能力，
混在一起算反而看不出自己到底卡在哪一關。對話結束時會列出這次你用出了哪些字。

**聽得懂但講不出來 → 自動提前複習**
AI 在對話中用了某個單字本的字，你整場都沒跟著用 —— 這是很強的訊號：
它停在被動詞彙。程式會把這種字的複習日拉到明天，並在候選字池裡加權，
讓它更快再出現一次。**純本地判斷，不呼叫任何 API。**

**想講但講不出來 → 挖出你缺的字**
對話結束時，模型看一次整份逐字稿，找出你用很繞的說法、含糊的字（thing、stuff、
very very good）或明顯卡住的地方，指出你當下需要的那個字：

> 你說：the thing you do when you don't want to
> **reluctantly** 不情願地
> I did it reluctantly.　[加入單字本]

一整場對話只呼叫**一次** API，設定裡可以關掉。這是把你的弱點反向變成教材，
而不是從課本發一張單字表給你。

**查詢快取**
查過的字永久存在本機，同一個字一輩子只呼叫一次 API。
批次貼上時也會先扣掉已經查過的，只送真正的新字出去。
遇到多義字給錯語意時，彈窗的 ↻ 可以強制重查。

**練習紀錄**
連續天數、每週與累計練習時間、開口字數、練習熱力圖，以及每一場對話的完整逐字稿。
可整包匯出備份（**不含金鑰**）換裝置用。


## 兩個已知限制

**Groq 的跨來源政策**
Gemini 官方就支援瀏覽器直連，最穩定，所以預設用它。Groq 多數情況也可以，
但萬一被瀏覽器擋下，程式會顯示明確訊息請使用者改用 Gemini —— 不會靜默失敗。

**微軟 Edge 朗讀服務（設定裡的第二個語音選項）**
音質最好且免費無限，但微軟會擋部分來源 IP（雲端與資料中心幾乎都被擋，
一般家用網路通常沒問題）。連不上時會自動退回瀏覽器內建語音並在對話中告知，
不會中斷練習。

## 疑難排解

**按了開始卻沒反應／沒有麥克風權限**
確認網址是 `https://` 或 `localhost`。點網址列左側的圖示把麥克風改成「允許」。

**AI 一直自問自答**
麥克風收到喇叭的聲音了。戴耳機，或把設定裡的「搶話靈敏度」調成「低靈敏」。

**出現 429 或額度錯誤**
免費額度暫時用完。等幾分鐘，或到設定切換另一個供應商。

**模型 404 / model not found**
供應商汰換模型了。到設定按「抓取可用清單」重選一個即可。

**換電腦後資料不見**
資料存在瀏覽器本機。到「紀錄 → 匯出備份」存成 JSON，在新裝置匯入。
